## 관리 기준

- 개인 프로젝트이므로 김용현이 작성과 최종 검토를 담당한다. GPT는 초안 작성과 검토 보조에 활용한다.
- D02의 ‘작성 완료’는 차터 v1.0의 로컬 저장을 확인했다는 뜻이다. 제출·승인 여부는 확인 후 기록한다.
- 문서를 작성하거나 개정하면 해당 행의 파일 경로, 상태, 버전을 함께 갱신한다.
- 관련 요구사항은 D03에서 번호를 정한 뒤 연결한다. ‘—’는 아직 부여하지 않은 값이다.
