# 1:1 에어하키 대전 로봇 요구사항 명세서

D03 · 작성 김용현 · 검토 중 · v0.1 · 2026-11-24  
관련 문서: [문제 정의서](./problem.md)

## 1. 목표와 요구사항 계층

| 계층 | 요구 |
|---|---|
| 사용자 | 혼자 온 플레이어가 자기 패들만 조작해 로봇과 한 경기를 끝까지 치를 수 있다. |
| 시스템 | Python과 MuJoCo에서 양측의 타격, 랠리, 득점, 재개, 3점 선승 종료를 연결한다. |
| 하위 기능 | 입력부는 마우스 위치를 패들의 목표 위치로 변환한다. 로봇은 퍽을 관측해 평면 2축 패들을 움직인다. 경기 진행부는 득점과 승패를 판정하고 검증에 필요한 이벤트를 기록한다. |

확정한 경기 규칙은 마우스 조작, 플레이어 선공, 3점 선승, 실점한 쪽에서 재개이다.

## 2. 요구사항과 확인 방법

| ID | 종류 | 요구사항 | 우선 | 확인 방법 |
|---|---|---|---|---|
| R-01 | 경기 시작 | 새 경기는 0:0으로 시작한다. 퍽 1개를 플레이어 진영에 정지 상태로 배치해 플레이어가 선공한다. | 필수 | 첫 경기와 재경기에서 점수, 퍽 수, 배치 위치와 속도를 확인한다. |
| R-02 | 플레이어 입력 | 마우스로 자기 진영 안의 패들 목표 위치를 지정한다. 플레이어는 패들을 퍽에 접촉시켜 타격한다. | 필수 | 정지한 퍽에서 떨어져 마우스를 움직일 때와 패들로 퍽을 칠 때의 퍽 속도를 비교한다. |
| R-03 | 이동 제한 | 두 패들의 외곽은 각자 자기 진영 안에 머문다. 로봇 이동 명령에는 평면 속력과 가속도 상한을 적용한다. | 필수 | 중앙선 너머와 벽 밖에 목표를 주어 패들 외곽 이탈이 0회인지 확인한다. 제어 주기별 명령 속력과 가속도를 상한과 비교한다. |
| R-04 | 기본 반격 | 로봇은 자기 진영에서 접근 가능한 왼쪽·중앙·오른쪽 위치에 정지한 퍽을 스스로 쳐 상대 진영으로 보낸다. | 필수 | 세 위치에서 각각 1회 시험한다. 세 위치 모두 유효 반격이면 통과한다. |
| R-05 | 랠리 | 같은 랠리에서 사람 타격 → 로봇 유효 반격 → 사람 재타격이 1회 이상 성립한다. | 필수 | 저속 조건에서 직접 플레이하고 타격 순서와 중앙선 통과를 확인한다. 중간에 득점이나 퍽 재배치가 발생하면 별도 랠리로 센다. |
| R-06 | 득점 | 퍽 전체가 골문 안쪽으로 골라인을 통과하면, 그 골문을 수비하던 쪽의 상대에게 정확히 1점을 준다. | 필수 | 양쪽 골문에서 부분 통과, 완전 통과, 이후 연속 프레임 체류를 시험한다. 각 단계에서 추가되는 점수는 순서대로 0점, 1점, 0점이다. |
| R-07 | 경기 재개 | 득점 후 양측 모두 3점 미만이면 점수를 유지하고 실점한 쪽 진영에 퍽을 배치해 재개한다. | 필수 | 플레이어 득점과 로봇 득점을 각각 시험해 재개 위치와 점수를 확인한다. |
| R-08 | 경기 종료 | 어느 한쪽이 3점에 도달하면 승자를 표시하고 해당 경기의 득점과 재개 처리를 종료한다. | 필수 | 2:2에서 플레이어 득점 시 3:2, 로봇 득점 시 2:3으로 종료되는지 확인한다. 종료 후 추가 골 이벤트에도 점수가 유지되고 새 서브가 발생하지 않아야 한다. |
| R-09 | 경기 완주 | 한 사람이 로봇 패들을 대신 조작하거나 경기를 수동 복구하지 않고 시작부터 승패 결정까지 1경기 이상 완료할 수 있다. | 필수 | 완료한 경기의 최종 점수, 승자, 대리 조작 0회, 수동 복구 0회를 확인한다. 득점 후 규칙에 따른 자동 재개는 복구 횟수에서 제외한다. |
| R-10 | 성능 측정 | 퍽 속도별로 전체 시도 수, 접촉에 성공한 시도 수, 유효 반격에 성공한 시도 수를 기록한다. | 권장 | 아래 세 경로에서 속도만 바꿔 시험하고, 각 속도에서 접촉률과 유효 반격률을 별도로 계산한다. |

## 3. 판정 기준과 초기 시험 조건

- **유효 반격**: 로봇 패들이 자기 진영에서 퍽을 친 뒤, 다음 플레이어 타격·득점·재배치 전에 퍽 중심이 중앙선을 넘어 상대 진영에 진입한 경우다. 한 시도에서 여러 번 접촉해도 반격 성공은 최대 1회다.
- **저속 랠리 시험**: 플레이어의 첫 타격 직후 퍽 속력 0.50 ± 0.05 m/s를 초기 시험 범위로 제안한다. 시험마다 실제 속력을 기록한다.
- **속도 비교 시험**: 초기 퍽 속력 0.5, 1.0, 1.5 m/s에서 각각 골문 왼쪽·중앙·오른쪽을 향하는 세 경로를 1회씩 시험한다. 총 9회다. 같은 경로에서는 출발 위치·방향, 패들 시작 위치, 제어 설정을 유지한다. 경로 좌표는 장면 v0에서 정한다.
- **결과 해석**: 각 속도의 접촉률은 ‘접촉한 시도 수 ÷ 3’, 유효 반격률은 ‘유효 반격에 성공한 시도 수 ÷ 3’이다. 이는 정해진 세 경로의 결과이며 전체 경기에서의 성공 확률은 별도로 측정해야 한다.
- **로봇 명령 상한 초안**: 평면 속력 1.0 m/s, 가속도 크기 3.0 m/s². 이 값과 위 시험 속도는 미검증 설계값이다. 변경하면 사유와 버전을 기록하고 같은 설정으로 비교 시험을 다시 수행한다.
- **시험 증거**: 득점·재개·종료는 예상값을 먼저 정한 판정 테스트로 확인한다. 실제 반격·랠리·완주는 MuJoCo 실행 로그와 플레이 기록으로 확인한다.

## 4. 범위와 우선순위

4주 동안 기본 반격, 사람과의 랠리, 한 경기 완료 순으로 검증한다. 실물 장치 제작, 카메라 인식, 강화학습, 코너 조준과 벽 반사를 노리는 고급 전술은 이번 버전의 범위 밖이다.
